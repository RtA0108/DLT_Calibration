# 실제 프로젝터 테스트 방법

빔 프로젝터와 실물로 캘리브레이션을 테스트하는 순서입니다.
지금까지는 가상 프로젝터로만 검증했으므로, 처음 한 번은 **4장의 연습 시행**부터 하세요.

> 빌드(실행 파일)로는 아직 테스트할 수 없습니다(버텍스 클릭, Resources 쓰기 등). **Unity 에디터 플레이 모드**로 진행합니다.

---

## 1. 준비물

- 빔 프로젝터, HDMI 케이블
- 실물: Unity 모델과 **모양이 같은** 물체 (크기는 달라도 됨. 보정이 크기 차이를 흡수함)
- 실물과 프로젝터를 고정할 받침 (테스트 중 움직이면 안 됨)
- 자 또는 줄자 (어긋난 정도를 mm로 재기)
- 휴대폰 카메라 (결과 기록)
- 기록 표 (5장)

---

## 2. 장비 설치 (테스트 전날 해 두면 좋음)

**프로젝터**
1. 실물을 비출 위치에 프로젝터와 실물을 **단단히 고정**합니다.
2. 줌, 초점, 렌즈 시프트를 맞춘 뒤 **이후 건드리지 않습니다.**
3. 아래 기능은 끕니다. 화면을 스스로 바꾸면 보정이 깨집니다.
   - 자동 키스톤, 자동 맞춤, 자동 초점
   - 디지털 줌, 오버스캔 (화면비는 "원본/1:1"로)
   - 에코 모드, 신호 없음 자동 꺼짐
4. 키스톤 보정은 0으로 둡니다. 보정 계산이 기울어짐을 흡수합니다.
5. 켠 뒤 10~20분 예열합니다. 예열 중에는 초점이 조금씩 바뀝니다.

**Windows**
1. 디스플레이 설정에서 프로젝터를 **확장** 모드로 둡니다 (복제 아님).
2. 프로젝터 디스플레이 해상도는 **프로젝터 기본(권장) 해상도**, 배율은 **100%**로 둡니다.
3. 작업 표시줄은 주 모니터에만 표시합니다.
4. 절전과 화면 보호기는 끕니다.

---

## 3. Unity 설정 (플레이 전에)

1. **프로젝터용 Game 창 만들기**
   - 메뉴 **Window > General > Game**으로 Game 창을 하나 더 엽니다.
   - 새 창 왼쪽 위 **Display 1**을 **Display 2**로 바꿉니다.
   - 탭을 끌어 떼어 낸 뒤, 프로젝터 화면으로 옮겨 **화면을 꽉 채웁니다(최대화).**
2. **프로젝터 Game 창 툴바 설정**
   - 해상도: **Free Aspect**
   - 같은 메뉴의 **Low Resolution Aspect Ratios**: 끔
   - **Scale: 1x**
   - **Gizmos, Stats**: 끔
3. **조작용 Game 창(Display 1)**: 툴바의 **Play Focused**로 둡니다. **Play Maximized는 쓰지 마세요.** 프로젝터 창이 가려집니다.
4. 창 배치를 끝낸 뒤 플레이합니다. **플레이 중에는 프로젝터 창을 옮기거나 크기를 바꾸지 마세요.** 보정은 그 창의 픽셀 크기 기준이라, 바뀌면 다시 보정해야 합니다.

참고:
- Game 창 위쪽 탭과 툴바 부분도 실물 쪽으로 투사됩니다. 실물이 화면 맨 위 가장자리에 걸리지 않게 두세요.
- 마우스 커서도 투사됩니다. 맞출 때는 커서 끝을 기준으로 보면 됩니다.

## 4. 진행 순서

### 4-1. 시작 확인
1. 플레이를 누르고, 오른쪽 목록에서 모델을 고릅니다. 크기는 프로젝터 화면에 맞게 자동으로 조절됩니다.
2. 프로젝터에 모델이 검은 배경 위로 보이는지 확인합니다. 이 시점에는 실물과 안 맞는 게 정상입니다.
3. 필요하면 회전 슬라이더로 실물과 **대충** 같은 방향으로 돌립니다. **보정 뒤에는 슬라이더를 건드리지 않습니다.**
   - 크기 슬라이더는 불러올 때 맞춘 크기의 %(25~400%)입니다. 크기는 보정 결과에 영향이 없으니, 마커가 서로 겹치지 않을 만큼이면 충분합니다.

### 4-2. 대응점 고르기 (조작 화면, Display 1 창)
조작 화면 왼쪽 아래 상태 줄에 **지금 할 일**(`다음: …`)이 나옵니다. 막히면 그 줄을 보세요.

1. 조작용 Game 창을 한 번 클릭해 선택된 상태로 만듭니다. 키 입력은 선택된 Game 창에만 들어갑니다.
2. **- / =** 로 추천점 개수를 정합니다. **처음에는 10개를 추천합니다.**
   - 6개는 수학적 최소라 잘못 놓은 마커를 알아챌 방법이 없습니다.
3. **R**: 추천점이 대응점으로 선택되고, 프로젝터에 번호 붙은 십자선 마커가 나타납니다.
   - 캘리브레이션 모드(1)와 추천점 표시(3)가 꺼져 있으면 R이 자동으로 켭니다. 모델을 바꾼 뒤에도 R만 누르면 됩니다.
   - 조작 화면의 선택된 버텍스 옆에 **마커와 같은 번호**가 붙습니다.
4. 버텍스를 직접 고르거나 빼려면 조작 화면에서 클릭합니다. 커서 근처의 보이는 버텍스가 **노란 점**으로 미리 표시되고, 클릭하면 그 점이 선택/해제됩니다.

### 4-3. 마커 맞추기 (프로젝터 화면, Display 2 창)
1. **V** (정렬 보기): 모델 투사를 끄고 마커만 비춥니다. 실물이 잘 보입니다.
2. 마우스를 프로젝터 화면으로 옮겨 **프로젝터 창을 한 번 클릭**합니다. 첫 클릭은 창 선택에만 쓰일 수 있습니다.
3. 각 십자선을 끌어서 **가운데 빈 칸이 실물의 그 지점에 오게** 놓습니다.
   - 몇 번이 실물의 어디인지는 **조작 화면의 같은 번호**를 보면 됩니다. 지금 잡은 마커는 조작 화면에서도 노란색으로 크게 표시됩니다.
   - 좌우 눈처럼 비슷하게 생긴 곳이 두 군데 있으면 조작 화면 번호로 어느 쪽인지 확인하세요.
4. **방향키**로 마지막에 끈 마커(노란색)를 1px씩, **Shift+방향키**로 10px씩 옮길 수 있습니다. 마지막 몇 픽셀은 방향키로 맞추는 게 편합니다.
5. 색으로 진행 상황을 봅니다: **흰색** = 아직 안 맞춤, **초록** = 맞춤, **노랑** = 지금 움직이는 마커.
6. 맞춘 마커가 **6개가 되면** 그때부터 놓을 때마다 맞춘 마커들로 자동 보정됩니다.
   - 콘솔에 `[Live] 맞춘 점 n개로 다시 계산: 재투영 RMSE …px`가 나옵니다.
   - **3px 넘게 맞지 않는다는 경고**가 나오면, 투영을 보고 어긋난 부분의 마커를 다시 맞춥니다.
7. 나머지 마커도 모두 맞춥니다. 이미 놓은 마커를 다시 옮겨도 됩니다.

참고: **T**로 마커 주변 모양(패치)을 켤 수 있습니다(끔 → 선 → 텍스처). 기본은 꺼져 있습니다.

### 4-4. 확인
1. **V**를 다시 눌러 모델 투사를 켜고, 텍스처가 실물에 맞는지 봅니다.
2. 조작 창을 클릭하고 **F**를 한 번 누릅니다. 자세한 결과가 콘솔에 나옵니다.
   - `[Calibration Info] … (화면 W x H)`의 크기가 **프로젝터 해상도(또는 프로젝터 창 크기)와 같은지** 확인합니다. 640x480이면 프로젝터 창이 Display 2로 설정되지 않은 것입니다.
   - F는 **선택된 점 전부**로 계산합니다. 모든 마커를 맞춘 뒤에 누르세요.
3. 기록합니다 (5장).

### 하면 안 되는 것
- 보정 뒤 **R**: 모든 마커가 지워집니다.
- 보정 뒤 모델 바꾸기: 마커가 지워집니다.
- 보정 뒤 슬라이더 이동: 투영이 어긋납니다. 움직였으면 **F**를 다시 누르면 같은 마커로 다시 맞춰집니다.
- 플레이 중지: 보정 결과는 저장되지 않습니다. 기록을 먼저 남기세요.

## 5. 기록할 것

시행마다 아래를 적습니다.

| 항목 | 어디서 |
|---|---|
| 모델, 추천점 개수 | 직접 |
| 맞추는 데 걸린 시간 | R부터 마지막 마커까지, 스톱워치 |
| 재투영 RMSE, 최대 (px) | F 후 콘솔 `[Reprojection]` |
| 카메라 값 | F 후 콘솔 `[Calibration Info]` 두 줄 |
| 실물 위 어긋남 (mm) | 아래 "확인 지점" |
| 사진 | 같은 위치에서 V 켠 상태 / 끈 상태 |
| 어려웠던 점 | 직접 (어느 번호가 찾기 어려웠는지 등) |

**확인 지점 (실제 정확도)**
- 재투영 RMSE는 "마커들이 서로 얼마나 일관된가"이지 실제 정확도가 아닙니다.
- 실제 정확도는 **보정에 쓰지 않은 곳**에서 잽니다. 실물에서 눈에 띄는 곳 3~5군데(눈, 부리 끝, 모서리 등)를 미리 정해 두세요.
- V를 끈 상태에서 투사된 텍스처의 그 부분과 실물의 그 부분이 몇 mm 어긋나는지 자로 잽니다.

**콘솔을 놓쳤을 때**
콘솔 내용은 모두 `C:\Users\minsu\AppData\Local\Unity\Editor\Editor.log`에 남습니다. 에디터를 다시 켜면 이 파일은 새로 쓰이고, 이전 내용은 `Editor-prev.log`로 한 번만 보관됩니다.

**콘솔에서 무시할 것**
- `[Sim] GT 대비 …`: 가상 시뮬레이션용 값이라 실제 테스트에서는 의미 없습니다.
- `[Residual] 마커 평균 이동량`: 처음 위치에서 얼마나 옮겼는지일 뿐입니다.

## 6. 시행 계획 (추천)

1. **연습 1회**: Chick, 10개, 선 패치. 조작에 익숙해지는 것이 목적이라 기록은 참고만.
2. **본 시행**: 같은 모델로 추천점 개수 **6 → 10 → 15**, 개수마다 2~3회.
3. 여유가 있으면 **TheRock(각진 low poly)**으로 같은 순서를 반복합니다. 선 패치가 모서리를 그려서 찾기 쉬운지 비교합니다.

**시행마다 플레이를 다시 시작하세요.** 보정된 카메라가 남아 있으면 다음 시행의 마커가 이미 거의 맞는 자리에서 시작해서, 시간과 정확도 비교가 공정하지 않게 됩니다.

## 7. 문제가 생기면

| 증상 | 확인할 것 |
|---|---|
| 마커가 안 끌림 | 프로젝터 창을 먼저 한 번 클릭. 마우스가 프로젝터 창 안에 있는지 |
| 키(1, 3, R, V, F)가 안 먹음 | Game 창이 선택돼 있는지 (Scene 창이 선택돼 있으면 F는 "선택 오브젝트로 이동") |
| 프로젝터에 아무것도 안 나옴 | 프로젝터 창이 Display 2인지, 플레이 중인지 |
| `(화면 640x480)`로 나옴 | 프로젝터 창이 Display 2로 설정되지 않았거나 닫혀 있음 |
| 보정 후 투영이 실물과 크게 다름 | 비슷하게 생긴 다른 곳에 맞춘 마커가 없는지 (좌우 대칭인 부분 등) |
| "좌우가 뒤집힌 해" 경고 | 마커 짝이 섞임. 번호 확인 후 다시 맞춤 |
| "거의 한 평면" 경고 | 추천점이 한 면에 몰림. 개수를 늘리거나 모델 방향을 바꿔 다시 R |
| 투영이 점점 어긋남 | 프로젝터나 실물이 움직였거나 예열 중. 고정 확인 후 다시 맞춤 |
| 가장자리로 갈수록 어긋남 | 렌즈 왜곡일 수 있음 (보정이 다루지 못함). 기록해 두기 |
| 모델이 갑자기 사라짐 | 콘솔에 `far를 … 로 늘렸습니다`가 있는지. 없으면 알려주세요 |

## 8. 테스트 후 알려주시면 좋은 것

- 기록 표와 사진
- 어느 단계가 가장 어려웠는지 (점 찾기, 패치 보기, 드래그, 키 조작 등)
- 경고가 자주 떴는지, 어떤 경고였는지
- 실물 위 어긋남이 어디서 컸는지 (가운데 / 가장자리)
